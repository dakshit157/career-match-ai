# 🎯 CareerMatch AI — AI-Powered Resume & Job Match Analyzer

> **Project:** CareerMatch AI  
> **Type:** Standalone Web Application  
> **Stack:** Next.js (TypeScript, Tailwind CSS) • Python FastAPI • AI Analysis Engine

---

## 💡 About CareerMatch AI

**CareerMatch AI** helps students, recent graduates, and job applicants evaluate how well their resume aligns with target job postings using advanced **AI Analysis**.

It extracts resume credentials in-memory, identifies matching vs. missing skills, provides honest resume suggestions, and generates tailored portfolio project ideas and a prioritized learning roadmap to bridge qualification gaps.

---

## 🏆 Evaluation & Demo Guide

Evaluators and users **do NOT need to enter an API key** to review the complete application:

### 1. Instant Demo Mode (No API Key Required)
- Click the **"Try Demo Analysis"** button on the home page.
- Instantly loads a complete, verified evaluation of a Junior Data Scientist resume against an employer job description.
- Clearly watermarked with `Demo Data — Not a live AI analysis` to maintain 100% transparency.
- Explore the match score (78/100), category breakdown, verified vs. missing skills, resume improvement checklist, portfolio project cards, and prioritized learning roadmap.

### 2. Live AI Analysis Mode (With Owner-Configured Backend Key)
- The application owner configures `GEMINI_API_KEY` once as a secure secret on the **backend server**.
- Evaluators or users can upload any valid PDF resume (up to 5 MB), paste any job description, and click **"Analyze My Match"** to get a live, personalized evaluation generated by the AI analysis engine.
- Users are never asked to provide or enter their own API keys on the frontend.

---

## 🚀 Key Features

- **In-Memory PDF Resume Processing:** Upload standard PDF resumes (up to 5 MB). Resumes are processed in RAM without permanent server storage.
- **Job Description Match Scoring:** Instant 0–100 match score with category alignment (Technical Skills, Experience, Education).
- **Three-Tier Skills Classification:**
  - 🟢 **Matching Skills:** Direct alignment supported by the resume.
  - 🔴 **Missing Skills:** Key employer requirements absent from the resume.
  - 🟡 **Skills to Strengthen:** Skills mentioned on the resume that need deeper proof or practical application.
- **Actionable Resume Suggestions:** Practical suggestions to improve bullet points and quantify impact without fabricating experience.
- **Targeted Portfolio Projects:** Concrete project ideas with tech stacks specifically chosen to bridge missing skills.
- **Prioritized Learning Roadmap:** Phased step-by-step action items to master target requirements.
- **Privacy & Security Focused:** In-memory document parsing; transparent disclosure that resume text is analyzed securely via AI services without persistent retention.

## ⚡ Local Quick Start

### 1. Launch with One Click (PowerShell)
```powershell
.\run-dev.ps1
```
This automatically starts:
- **FastAPI Backend:** `http://localhost:8000` (API Docs: `http://localhost:8000/docs`)
- **Next.js Frontend:** `http://localhost:3000`

---

### 2. Or Run in Two Separate Terminals

#### Terminal 1: Backend (FastAPI)
```powershell
cd backend
.\.venv\Scripts\Activate.ps1
python main.py
```

#### Terminal 2: Frontend (Next.js)
```powershell
cd frontend
npm run dev
```
Open **`http://localhost:3000`** in your browser.

## 🌐 Deployment Instructions

### 1. Backend Deployment (e.g., Render, Railway, Fly.io)
1. Deploy the `backend/` folder as a Python web service.
2. In the hosting platform's dashboard, configure the following **Environment Variables**:
   ```env
   GEMINI_API_KEY=your_backend_api_key
   PORT=8000
   CORS_ORIGIN=https://your-frontend-domain.vercel.app
   ```
3. Start command:
   ```bash
   uvicorn main:app --host 0.0.0.0 --port $PORT
   ```

### 2. Frontend Deployment (e.g., Vercel)
1. Deploy the `frontend/` folder to Vercel.
2. In Vercel Project Settings $\rightarrow$ Environment Variables, set:
   ```env
   NEXT_PUBLIC_API_URL=https://your-backend-domain.onrender.com
   ```
3. Deploy! The frontend will communicate with your deployed backend.

> **Security & Privacy Note:**  
> • The backend API key (`GEMINI_API_KEY`) is kept strictly on the backend hosting platform as a secret environment variable and is **never** exposed to the frontend or browser.  
> • Uploaded PDF resumes are read into memory streams and discarded immediately after analysis. No resumes are saved to disk or persistent databases.
